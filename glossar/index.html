KI-Glossar: 100+ Begriffe einfach erklärt

Die wichtigsten Fachbegriffe der KI-Welt – verständlich und praxisnah

ABCDE FGHIJ KLMNO PQRST UVWXYZ

A

AI

Artificial Intelligence
Tech

Die Fähigkeit von Maschinen, menschenähnliche Intelligenz zu zeigen – zu lernen, Probleme zu lösen und zu verstehen.

Beispiel: Siri, Netflix-Empfehlungen, autonomes Fahren

AGI

Artificial General Intelligence
Tech

Künstliche Allgemeine Intelligenz – eine hypothetische KI, die alle intellektuellen Aufgaben genauso gut wie ein Mensch lösen kann.

Beispiel: Noch Science-Fiction, aber Ziel vieler KI-Forschungslabore.

Algorithmus

Schritt-für-Schritt-Anleitung
Tech

Eine festgelegte Reihe von Anweisungen, die ein Computer befolgt, um ein Problem zu lösen.

Beispiel: Der Algorithmus von Google bestimmt die Suchergebnisse.

API

Application Programming Interface
Tech

Eine Schnittstelle, über die verschiedene Programme miteinander kommunizieren können.

Beispiel: Deine Wetter-App nutzt eine API für aktuelle Daten.

B

Bias

Verzerrung
Ethik

Wenn eine KI aufgrund ihrer Trainingsdaten Vorurteile entwickelt und Gruppen benachteiligt.

Beispiel: Ein Bewerbungsalgorithmus bevorzugt bestimmte Geschlechter.

Big Data

Massive Datenmengen
Business

Extrem große Datenmengen, die mit traditionellen Methoden nicht mehr verarbeitet werden können.

Beispiel: Facebook verarbeitet täglich Petabytes an Nutzerdaten.

Bot

Software-Roboter
Business

Ein automatisiertes Programm, das repetitive Aufgaben ausführt.

Beispiel: Kunden-Support-Chatbots, Twitter-Bots.

C

ChatGPT

KI-Chatbot von OpenAI
Tech

Ein Large Language Model, das natürliche Sprache versteht und generiert.

Beispiel: Schreibt Texte, beantwortet Fragen, programmiert.

Computer Vision

Computersehen
Tech

Die Fähigkeit von Computern, visuelle Informationen zu verstehen.

Beispiel: Gesichtserkennung, autonomes Fahren.

CNN

Convolutional Neural Network
Tech

Spezialisierte neuronale Netze für Bildverarbeitung.

Beispiel: Erkennung von Fußgängern in autonomen Fahrzeugen.

D

Deep Learning

Tiefes Lernen
Tech

Fortgeschrittenes Machine Learning mit neuronalen Netzen mit vielen Schichten.

Beispiel: Spracherkennung, Bildklassifizierung, autonomes Fahren.

Dataset

Datensatz
Tech

Eine Sammlung von Daten, die zum Trainieren einer KI verwendet wird.

Beispiel: ImageNet mit 14 Millionen Bildern für Bilderkennung.

Diffusion

Diffusionsmodell
Tech

Eine Technik zur Bildgenerierung, die Schritt für Schritt Rauschen entfernt.

Beispiel: Midjourney, Stable Diffusion – erzeugen Bilder aus Text.

E

Embedding

Vektor-Darstellung
Tech

Numerische Darstellung von Daten als Vektor – ermöglicht semantisches Verständnis.

Beispiel: "König - Mann + Frau = Königin" – semantische Beziehungen.

EU AI Act

EU-Verordnung
Ethik

Die erste umfassende KI-Gesetzgebung weltweit.

Beispiel: Klassifiziert KI-Systeme nach Risikostufen.

G

Generative AI

Kreative KI
Tech

KI-Systeme, die neue Inhalte erstellen – Texte, Bilder, Musik.

Beispiel: ChatGPT, Midjourney, Suno.

GPT

Generative Pre-trained Transformer
Tech

Eine Klasse von Sprachmodellen von OpenAI.

Beispiel: GPT-3.5, GPT-4, ChatGPT.

L

LLM

Large Language Model
Tech

Große Sprachmodelle, die menschenähnliche Sprache generieren.

Beispiel: GPT-4, Claude, Google Bard.

LangChain

KI-Framework
Tech

Ein Framework zur Entwicklung von KI-Anwendungen.

Beispiel: Chatbots, die auf Unternehmensdaten zugreifen.

M

Machine Learning

Maschinelles Lernen
Tech

Computer lernen aus Daten, ohne explizit programmiert zu werden.

Beispiel: Spam-Filter lernen aus markierten E-Mails.

Multi-Modal

Mehrere Eingabearten
Tech

KI-Systeme, die Text, Bilder, Audio und Video kombiniert verarbeiten.

Beispiel: GPT-4V analysiert Bilder und beschreibt sie.

N

NLP

Natural Language Processing
Tech

Die Fähigkeit, menschliche Sprache zu verstehen und zu generieren.

Beispiel: Übersetzungstools, Sprachassistenten.

Neuronales Netz

Neural Network
Tech

Ein Computermodell inspiriert vom menschlichen Gehirn.

Beispiel: Ein Netz mit Millionen Verbindungen lernt Muster.

P

Prompt

Eingabeaufforderung
Business

Deine Anweisung an eine KI. Gut formuliert = bessere Ergebnisse.

Beispiel: "Schreibe einen Blog-Artikel über Hunde für Anfänger."

Prompt Engineering

Prompt-Optimierung
Business

Die Kunst, präzise Anweisungen zu formulieren.

Beispiel: Rollen zuweisen, Beispiele geben, Format festlegen.

Python

Programmiersprache
Tech

Die beliebteste Sprache für KI und Data Science.

Beispiel: TensorFlow, PyTorch – alle KI-Frameworks nutzen Python.

R

RAG

Retrieval Augmented Generation
Tech

KI greift auf externe Wissensdatenbanken zu.

Beispiel: Unternehmenschatbot durchsucht interne Dokumente.

RLHF

Reinforcement Learning from Human Feedback
Tech

Training durch menschliches Feedback zur Verbesserung der Antworten.

Beispiel: ChatGPT wurde mit RLHF menschlichen Präferenzen angepasst.

T

Token

Texteinheit
Tech

Die kleinste Einheit, die eine KI verarbeitet – Wörter oder Wortteile.

Beispiel: "Hallo Welt" = ca. 3 Tokens. 1000 Wörter ≈ 1300-1500 Tokens.

Transformer

KI-Architektur
Tech

Die revolutionäre Architektur hinter modernen Sprachmodellen.

Beispiel: GPT, BERT, T5 basieren auf der Transformer-Architektur.

F

Fine-Tuning

Feinabstimmung
Tech

Das nachträgliche Trainieren eines vortrainierten KI-Modells mit spezifischen Daten für eine Aufgabe.

Beispiel: Ein GPT-Modell wird mit Kundenservice-Daten feinabgestimmt für bessere Antworten.

Foundation Model

Basis-Modell
Tech

Ein auf großen Datenmengen vortrainiertes KI-Modell, das für verschiedene Aufgaben angepasst werden kann.

Beispiel: GPT-4, Claude, Llama – alles Foundation Models.

H

Hallucination

Halluzination
Tech

Wenn eine KI falsche oder erfundene Informationen als Fakten präsentiert.

Beispiel: ChatGPT erfindet Quellen oder Fakten, die nicht existieren.

Human-in-the-Loop

Mensch im Prozess
Business

Ein Modell, bei dem menschliche Expertise in den KI-Prozess eingebunden wird.

Beispiel: KI schlägt Antworten vor, Mensch prüft und genehmigt sie.

I

Inference

Inferenz / Anwendung
Tech

Der Prozess, wenn ein trainiertes KI-Modell auf neue Daten angewendet wird.

Beispiel: ChatGPT generiert eine Antwort – das ist Inference.

AI Integration

KI-Integration
Business

Die Einbettung von KI-Funktionen in bestehende Software oder Arbeitsabläufe.

Beispiel: Microsoft 365 Copilot in Word, Excel und Teams integriert.

J

JSON

JavaScript Object Notation
Tech

Ein Datenformat zur strukturierten Speicherung und Übertragung von Daten, häufig in KI-APIs verwendet.

Beispiel: KI-Modelle geben strukturierte Daten als JSON aus für weitere Verarbeitung.

K

Knowledge Base

Wissensdatenbank
Business

Eine strukturierte Sammlung von Informationen, auf die KI-Systeme zugreifen können.

Beispiel: Unternehmenswiki, das von einem RAG-System durchsucht wird.

KPI

Key Performance Indicator
Business

Kennzahlen zur Messung des Erfolgs von KI-Implementierungen im Unternehmen.

Beispiel: Zeitersparnis, Kostenreduktion, Kundenzufriedenheit durch KI.

O

OCR

Optical Character Recognition
Tech

Technologie zur Erkennung von Text in Bildern oder gescannten Dokumenten.

Beispiel: KI liest und digitalisiert handschriftliche Notizen oder Rechnungen.

Open Source

Offene Software
Tech

KI-Modelle oder Tools, deren Quellcode frei verfügbar und nutzbar ist.

Beispiel: Llama, Stable Diffusion, LangChain – alles Open Source.

Q

Quantisierung

Model Optimization
Tech

Eine Technik zur Reduzierung der Modellgröße für schnellere Berechnungen mit minimaler Qualitätsverlust.

Beispiel: Ein 70B-Parameter-Modell läuft auf einem Laptop durch Quantisierung.

S

Supervised Learning

Überwachtes Lernen
Tech

Training eines Modells mit gelabelten Beispielen (Input + gewünschter Output).

Beispiel: KI lernt Spam-Erkennung durch markierte E-Mails.

System Prompt

Systemanweisung
Tech

Hintergrundanweisungen, die dem KI-Modell sein Verhalten und seine Rolle definieren.

Beispiel: "Du bist ein professioneller Business-Coach. Antworte stets höflich und präzise."

Semantic Search

Semantische Suche
Tech

Suche nach Bedeutung statt nach exakten Keywords – versteht Kontext und Synonyme.

Beispiel: Suche nach "Autoreparatur" findet auch "Werkstatt" und "Kfz-Service".

U

Unsupervised Learning

Unüberwachtes Lernen
Tech

KI findet Muster in Daten ohne vorherige Labels oder Beispiele.

Beispiel: KI gruppiert Kunden automatisch in Segmente basierend auf Kaufverhalten.

User Experience (UX)

Benutzererfahrung
Business

Die Gesamterfahrung eines Nutzers mit einem KI-gestützten Produkt oder Service.

Beispiel: ChatGPT ist erfolgreich wegen seiner einfachen, intuitiven Bedienung.

V

Vector Database

Vektordatenbank
Tech

Spezialisierte Datenbank zur Speicherung und Suche von Embeddings/Vektoren.

Beispiel: Pinecone, Weaviate, Chroma – für RAG-Systeme und semantische Suche.

Validation

Validierung
Tech

Überprüfung der KI-Performance mit Testdaten vor dem Produktiveinsatz.

Beispiel: Ein Modell wird mit 20% der Daten getestet, mit denen es nicht trainiert wurde.

W

Workflow Automation

Workflow-Automatisierung
Business

Die automatische Ausführung von Geschäftsprozessen durch verknüpfte Tools und KI.

Beispiel: E-Mail-Anfrage → KI-Kategorisierung → automatische Antwort → CRM-Eintrag.

Weights

Gewichte
Tech

Die trainierbaren Parameter eines neuronalen Netzes, die das "Wissen" des Modells speichern.

Beispiel: GPT-4 hat hunderte Milliarden Weights, die beim Training optimiert werden.

X

XAI

Explainable AI
Ethik

Erklärbare KI – Methoden, um KI-Entscheidungen für Menschen nachvollziehbar zu machen.

Beispiel: Warum hat die KI diesen Kredit abgelehnt? XAI zeigt die Gründe.

Y

YAML

Yet Another Markup Language
Tech

Ein menschlich lesbares Datenformat, oft für KI-Konfigurationen und Prompt-Templates.

Beispiel: Konfiguration von LangChain-Chains oder Prompt-Strukturen in YAML.

Z

Zero-Shot

Ohne Beispiele
Tech

KI löst eine Aufgabe ohne je ein Beispiel dafür gesehen zu haben.

Beispiel: Übersetzung in eine Sprache ohne vorherige Übungen.
